# Lesson 8: Yougile API tests

Before running the tests, set the API token in an environment variable:

```text
YOUGILE_API_TOKEN=<Yougile API key>
```

If the company uses a custom API address, it can be provided separately:

```text
YOUGILE_BASE_URL=https://yougile.com/api-v2
```

Run the tests from this directory with:

```text
pytest lesson_08
```
